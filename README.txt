BIMS — kode sumber HTML

Struktur:
  index.html          Markup 12 layar (satu <template id="tpl-..."> per layar)
  assets/styles.css   Gaya global
  assets/app.js       Runtime kecil + logika tiap layar (teks EN/ID, data contoh, interaksi)
  assets/logo.jpg     Logo

Cara membuka: klik dua kali index.html (font memerlukan internet; tanpa internet memakai font cadangan).
Pindah layar: tombol "Pages / Halaman" di kanan bawah, atau alamat index.html#/NamaLayar
  (Main, Register, WorkspaceStatus, Login, SuperAdmin, AdminDashboard, AdminClasses,
   TutorClass, StudentHome, Exam, Result, AccessMatrix).
Ini prototipe desain: belum terhubung ke server, database, atau login sungguhan.
